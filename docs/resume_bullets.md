# Resume Version

## Project Title

ML Experiment Control Platform | FastAPI, React, PostgreSQL, Redis, Docker, Kubernetes

## Resume Bullets

- Built a full-stack ML experiment platform using FastAPI, React, SQLAlchemy, PostgreSQL, and Docker to launch experiments, track metrics, stream logs, and compare model runs.
- Implemented backend APIs for experiment lifecycle management, metric history, artifact browsing, and side-by-side model comparison with OpenAPI documentation and pytest coverage.
- Designed a React TypeScript dashboard with live log streaming, run filters, KPI cards, validation-loss visualizations, artifact panels, and comparison tables for ML workflow observability.
- Added Docker Compose, GitHub Actions CI, and Kubernetes deployment manifests to demonstrate production-oriented AI infrastructure and platform engineering practices.

## Short GitHub Description

Full-stack ML experiment tracking and monitoring platform with FastAPI, React, SQLAlchemy, PostgreSQL, Docker, CI/CD, and Kubernetes-ready deployment.
